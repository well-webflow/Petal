Modal Demo - Scroll Lock Feature

By default, modals lock the page scroll when opened. This prevents the background from scrolling while the modal is active, creating a better user experience. You can disable this by setting petal-lock-scroll-on-open="false".

Try it out:

  1. Scroll down this page a bit
  2. Click "Scroll Locked Modal" - notice you can't scroll the background page
  3. Close it and try "Scroll Unlocked Modal" - you can scroll the background

Modal Demo - Custom Animations

Override the default type-based animations with petal-anim-open and petal-anim-close attributes. You can set them independently — e.g. scale open, slide-down close.

Close Animation Examples:

  • Scale open → Slide-down close — opens with a pop, closes by sliding away
  • Slide-right open → Fade-out close — enters from the left, fades away on close
  • If no petal-anim-close is set, the close animation is automatically the reverse of the open animation

How Group Coordination Works:

  • All dropdowns above share petal-group="nav"
  • When you hover from one to another, the first closes before the second opens
  • Each dropdown has 600ms animations and 200ms close delay to make the effect more visible
  • The system calculates the total close time (delay + animation) and waits before opening the next dropdown
  • This creates a smooth, sequential navigation experience with no overlapping animations
  • Try hovering quickly between them to see the coordination in action!

Dropdown Demo - Nested Dropdowns

Dropdowns can be nested inside each other. Click the inner dropdown's close button - only the inner dropdown closes, not the outer one.

How It Works:

  • The outer dropdown (blue) contains an inner dropdown (green) in its menu
  • Clicking the inner dropdown's close button only closes the inner dropdown
  • Event propagation is stopped to prevent the outer dropdown from closing
  • Each dropdown operates independently with its own state
