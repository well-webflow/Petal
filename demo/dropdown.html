Mega Dropdowns

Note: Mega dropdowns feature a shared animated background that adjusts to the height of the active menu. Only one mega dropdown can be open at a time.

Window width: Mega dropdowns only work when the window is at least 992px wide. Below that they turn off, and your CSS decides how the menus look (for example, inside a mobile nav). Widen the window to try them out.
HOVER MODE
